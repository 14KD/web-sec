Instalación y Puesta en Marcha

Configura el entorno en menos de 1 minuto con Python 3.11+

bash — terminal

# 1. Clonar el repositorio

$ git clone https://github.com/tu-usuario/webtester.git

$ cd webtester


# 2. Instalar el paquete en modo desarrollo

$ pip install -e "./web test[dev]"


# 3. Ejecutar una auditoría ética

$ websec scan https://mi-dominio.com --i-have-permission

4 Modos Drásticos de Testeo

Superando los tests unitarios convencionales con validación matemática y de estrés continuo.

🔬

Property-Based Fuzzing

Genera miles de payloads, rutas corruptas e invariantes de puntuación matemática usando Hypothesis. Valida que el algoritmo jamás produzca puntajes inválidos ni desborde el alcance ético.

💥

Ingeniería de Caos

Inyección deliberada de caídas de red bruscas (TCP RST), bucles infinitos de redirección 302, respuestas masivas de 50MB (zip-bombs) y fallos 500 continuos sin interrumpir la sesión de escaneo.

🎯

Laboratorio E2E Real

Ejecución en vivo contra un servidor Flask vulnerable propio (lab/app.py). Valida que los 17 módulos detectan todas las vulnerabilidades OWASP reales de forma end-to-end.

🧠

Auditoría por Grafo

Inspección automatizada de graphify-out/graph.json. Verifica límites arquitectónicos limpios, previene acoplamiento bidireccional y comprueba la cobertura en el grafo de cada módulo.
