# Directrices Éticas y de Seguridad

WebSec Auditor ha sido concebido exclusivamente como una herramienta defensiva, educativa y de aseguramiento de software.

## Reglas Inquebrantables de Uso
1. **Consentimiento Expreso:** Nunca escanee un dominio sin la debida autorización por escrito del propietario legal del activo.
2. **Sin Explotación:** Esta herramienta identifica posibles vectores de riesgo mediante sondeos no destructivos. Queda terminantemente prohibido utilizar o modificar este software para extraer datos confidenciales, vulnerar credenciales o alterar sistemas.
3. **Respeto a la Disponibilidad:** El rate limiting está configurado por defecto a un nivel seguro (2 peticiones por segundo). No fuerce tasas excesivas que puedan degradar el servicio auditado.
4. **Protección de Datos:** Las evidencias registradas en los reportes nunca deben almacenar datos sensibles reales de usuarios finales.
